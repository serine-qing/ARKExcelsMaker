# 技能图标识别实现计划

## 目标

在现有浏览器端 OCR 网页中，根据干员名字的 OCR 坐标裁剪其上方的技能图标，与本地标准图标比较，输出干员携带的技能及可信度。识别过程全部在浏览器完成。

## 数据结构

前端使用一份干员与技能索引：

```json
{
  "name": "能天使",
  "characterId": "char_103_angel",
  "skills": [
    {
      "skillId": "skchr_angel_1",
      "name": "冲锋模式",
      "icon": "/skills/skchr_angel_1.webp",
      "hash": "f0c39a..."
    }
  ]
}
```

建议保存位置：

```text
public/data/operators.json
public/skills/*.webp
```

## 实现步骤

### 1. 识别并纠正干员名字

1. 保留 PaddleOCR 返回的文字、置信度和 `poly` 坐标。
2. 使用完整干员名单过滤识别结果。
3. 对轻微错字进行编辑距离模糊匹配。
4. 当匹配结果不唯一或差距过小时，标记为不确定，不自动选择。

### 2. 根据名字定位技能图标

名字和技能图标的相对位置固定，因此不依赖整张截图的绝对坐标：

1. 计算名字坐标框的中心、宽度和高度。
2. 根据文字高度推算技能图标大小。
3. 从名字中心向上偏移，得到技能图标区域。
4. 将裁剪区域限制在图片边界内。
5. 在页面中绘制调试框，方便校准。

裁剪参数单独配置：

```ts
interface SkillCropConfig {
  iconSizeByTextHeight: number;
  verticalGapByTextHeight: number;
  horizontalOffsetByTextHeight: number;
  paddingRatio: number;
}
```

初始值可从以下范围开始校准：

```ts
const cropConfig = {
  iconSizeByTextHeight: 2.5,
  verticalGapByTextHeight: 0.5,
  horizontalOffsetByTextHeight: 0,
  paddingRatio: 0.05,
};
```

这些数值必须根据实际编队截图调整，不能直接视为最终参数。

### 3. Canvas 裁剪和预处理

1. 使用 `drawImage` 从原图裁剪技能区域。
2. 统一缩放为 `64×64`。
3. 裁掉容易出现选中边框、角标的外围区域。
4. 分别生成灰度图和颜色数据。
5. 对截图图标和标准图标执行完全相同的处理。

### 4. 图标特征计算

第一版采用轻量纯前端方案：

- 感知哈希 pHash 或 dHash：判断主体结构是否相似。
- 颜色直方图：减少结构相似但颜色不同的误判。
- 可选的像素归一化相关度：在裁剪非常稳定时补充判断。

标准技能图标的哈希应在数据生成阶段提前计算，避免浏览器重复处理。

### 5. 候选匹配

不要与全游戏技能比较：

```text
OCR 得到干员名字
→ 查询该干员的技能列表
→ 只比较该干员的 1～3 个技能
→ 选择得分最高者
```

初始综合评分：

```text
最终分数 = 哈希相似度 × 70% + 颜色相似度 × 30%
```

增加拒绝条件：

- 最高分低于阈值，例如 `0.75`，返回“无法确定”。
- 第一名和第二名差值小于阈值，例如 `0.08`，返回“存在多个候选”。
- OCR 干员名字本身不确定时，不自动给出技能结论。

具体阈值应通过真实截图测试集确定。

### 6. 页面展示

每个识别结果展示：

- OCR 原始文字和纠正后的干员名字。
- 名字坐标框和技能裁剪框。
- 裁剪后的技能图标预览。
- 匹配到的标准技能图标和技能名称。
- 最终可信度及其他候选。
- 手动更正干员和技能的入口。

调试模式应允许实时调整裁剪参数，并显示调整后的区域。

## 测试计划

建立一组已人工标注答案的截图，覆盖：

- 不同截图分辨率和缩放比例。
- PNG、JPEG 和 WEBP 压缩。
- 技能图标选中效果和边框差异。
- 图标轻微遮挡或裁剪偏移。
- 干员名字 OCR 错字。
- 同一干员外观相似的技能图标。
- 图片带黑边或被二次裁剪。

记录以下指标：

- 干员名字匹配准确率。
- 技能裁剪成功率。
- 技能 Top-1 准确率。
- 拒绝率和错误接受率。
- 单张截图总处理耗时。

## 验收标准

- 能从典型编队截图中找到干员名字和对应技能区域。
- 已识别干员只与自己的技能进行比较。
- 低置信度结果不会被强行判定。
- 页面能展示裁剪图、候选技能和可信度。
- 浏览器端处理期间不上传用户截图。
- 在目标截图样本集上达到可接受的准确率后再默认启用。
